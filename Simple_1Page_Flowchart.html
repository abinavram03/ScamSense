🛡️ TrustLens - Simple Project Flowchart

Phishing Detection System for URLs & Messages

flowchart TD
    A["👤 STEP 1: USER INPUT
(Paste URL or Message)"] --> B["⚙️ STEP 2: FEATURE EXTRACTION
(URL Structure + Text Keywords)"]
    B --> C["🤖 STEP 3: ML MODEL & WHITELIST
(Random Forest Models + Safe Domain Check)"]
    C --> D["🔍 STEP 4: SHAP EXPLAINER
(Generates Plain-English Reasons)"]
    D --> E["📊 STEP 5: FINAL VERDICT
(Safe / Suspicious / Phishing)"]
STEP 1

User Input

User enters a web link or message text into the React Threat Console.

STEP 2

Feature Extraction

Backend checks 13 URL features (HTTPS, TLD, length) and text keywords (TF-IDF).

STEP 3

AI Analysis

Random Forest models compute risk scores. Known safe domains are whitelisted.

STEP 4

Explainable AI (SHAP)

Identifies exact reasons (e.g. "URL shortener used", "Requests OTP").

STEP 5

Result & History

Displays risk badge, reasons & advice, then saves record to MongoDB.

KEY ADVANTAGE

Why it Works

Combines multi-modal inputs, domain whitelisting, and human-readable XAI.
